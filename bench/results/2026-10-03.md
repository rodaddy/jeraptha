# Worker model benchmark, rounds 1 and 2 (2026-10-03)

Six tasks the author's private tooling monorepo had already finished, each
with a known-good reference, re-run from the same start commit with the same
brief. The task repo is private, so the briefs and hidden checks are not in
this repo; the task kinds are listed below. The numbers (829, 835 and so
on) are only the task ids of that private benchmark set, not references to
anything in this repo. Two rounds for the five native Claude settings, one round for
Codex Sol (added in round 2). Scored by script (`score.mjs`) with hidden
checks from the reference branches; the scorer passes every reference and
fails every start point.

## What the failures were

- 835 (most telling): the validator goes green either way; the failing runs
  silently delete the probes that prove the delete gate refuses `rm -rf`.
  Kept them: Opus medium both rounds, Fable once. Dropped them: Opus low,
  Sonnet low and Sonnet medium both rounds, Sol. The new assertion-guard
  refuses exactly this commit (probe count 10 -> 7).
- 836 round 1, Opus low and Sonnet low: gave up after a false gate-integrity
  refusal from a safety gate (a gate bug, fixed separately).
- 837: Opus medium round 1 and Sol stopped at a step the brief omitted.
  The operator ruled 2026-10-03 that lanes fill such in-scope gaps; later
  lane rules carry it.
- 832: exact-bytes round trip lost (Sonnet both settings in round 2), an
  unknown option accepted as text (Sonnet low round 1, Fable round 2), and
  `--help` exiting 3 (Fable round 2).

## Sol specifics

- Not usable as a Workflow lane: the Codex plugin runs on the ChatGPT account,
  which rejects `gpt-6.1-sol`. Runs went through `claudex sol high -p`.
- Started as a head, it tries to delegate (it did nothing on its first run);
  it needs "you are a worker lane, do it yourself".
- 8 to 16 minutes per task, about $1.20 to $1.50 each, and it staged without
  committing in 4 of 6 runs.
- Two of its launches failed with "proxy unavailable"; the local model proxy
  stalled for minutes twice that night.

## Scorer corrections (applied to every run equally)

- 838: dropped the reference-only footer text assertion.
- 832: channel_id accepts folder name or remote name; the `--help` output
  stream is not judged (the issue says "usage, exit 0" only).
- 835: added the check that the rm gate probes survive.

## Limits

Two runs per native cell, one for Sol. Six tasks, all the task repo's tooling and
docs work. Times include one-off gate refusals and proxy waits.

Raw ledgers, score files and patches stayed with the private task repo.

## What it changed

Worker routing by task type: Sonnet medium for docs-only and read-only lanes,
Opus medium for any lane touching code, tests, gates or safety. Opus medium
was the only setting that kept the safety probes in task 835 on both rounds.
